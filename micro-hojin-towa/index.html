マイクロ法人とは？メリット・デメリットと向いている人を公式情報で整理

この記事の結論
マイクロ法人は、個人事業主が小規模な法人を持つ方法の通称です。うまく使えば税金や社会保険の負担を調整できる可能性がありますが、必ず得をする仕組みではありません。法人は社会保険への加入が必要になり、決算・申告の手間や費用も増えます。向いているかどうかは、収入の構造と事業の内容によって変わるため、検討する場合は税理士に相談してください。

※当サイトでは、紹介するサービスを実際には利用していません。公式サイトや公的機関の公開情報をもとに整理しています。税務・社会保険の内容は一般的な情報であり、個別の状況に対する助言ではありません。最終的な判断は、税理士・税務署・年金事務所などの専門家・公的機関に確認してください。

マイクロ法人とは

「マイクロ法人」は、法律や税法で定められた用語ではなく、小規模な法人を指す通称です。一般には、個人事業主やフリーランスが、1人（または家族のみ）で運営する小さな法人を設立し、事業の一部または全部をその法人で行う形を指して使われます。ひとり法人、ひとり会社と呼ばれることもあります。

個人で稼ぐ形から法人化を考える流れは、フリーランスが法人化を検討する売上・所得の目安で整理しています。この記事では、特に「小さく始める法人」に絞って、仕組みと注意点を説明します。

マイクロ法人を検討する主な理由

1. 社会保険の形を変える

個人事業主は国民健康保険と国民年金に加入するのが一般的です。法人を設立すると、法人の事業所は、事業主のみの場合も厚生年金保険・健康保険の適用事業所になると、日本年金機構が案内しています。役員報酬の設定によって、社会保険料の水準や将来の年金・給付の考え方が個人事業主のときとは変わります。どちらが有利かは、収入、年齢、家族構成、自治体の国民健康保険の料率によって異なります。

2. 税金の負担を分けて考える

個人の所得税は所得が増えるほど税率が上がります。一方、資本金1億円以下の普通法人の法人税は、年800万円以下の部分が15%、超える部分が23.2%です（国税庁）。また、役員報酬を受け取る側は給与所得控除（令和8年分・令和9年分は最低74万円、上限195万円）を使える形になります（国税庁 No.1410）。法人側の税金（法人住民税、法人事業税など）や、役員報酬にかかる所得税・住民税、社会保険料まで含めて比較しないと、有利かどうかはわかりません。

3. 消費税の免税期間

国税庁の案内では、新たに設立された法人は、設立1期目・2期目に基準期間がないため原則として納税義務が免除されます。ただし、事業年度の開始日の資本金が1,000万円以上の場合や、特定新規設立法人にあたる場合、特定期間の課税売上高が1,000万円を超える場合、適格請求書発行事業者（インボイスの登録）を受けた場合などは、免除されません。取引先がインボイスを求める場合は、この前提が変わることもあります。

4. 取引先に対する信用や契約

法人名義で契約や口座を持ちたい、取引先から法人での契約を求められる、といった理由で設立する人もいます。たとえば、ギークスジョブのようなエージェントでは、法人での契約も可能で、そのために履歴事項全部証明書、法人印、法人名義の口座が必要とされています（エージェントの比較）。

デメリットと注意点

  • 社会保険に加入する負担：事業主のみの法人でも強制適用になります。保険料の負担が、国民健康保険・国民年金のときより増えるケースもあります。
  • 役員報酬を自由に変えられない：国税庁の案内では、役員給与は定期同額給与、事前確定届出給与、一定の業績連動給与のいずれにも当たらない部分は損金に算入されません。期の途中で金額を変えられる場合は限られます。
  • 赤字でもかかる税金がある：法人住民税は、法人税割と均等割からなります（東京都主税局）。均等割は定額の部分で、金額は自治体や資本金等の額、従業者数によって異なります。具体的な金額は、事務所のある自治体の公式サイトで確認してください。
  • 決算・申告の手間と費用：法人は決算書を作り、法人税の申告を行います。当サイトの税理士の費用の記事では、弥生株式会社の公開情報として、決算申告のみを依頼する場合の目安を15万〜25万円程度としています。事務所や内容で大きく異なります。
  • 設立の費用と手続き：設立には登録免許税や定款の手続き費用などがかかります。金額は法務局や公証役場など公式の情報で確認が必要です。この記事では確認できた範囲のみを記載しています。
  • 消費税の免税が使えない場合がある：前述のとおり、資本金や特定期間、インボイスの登録の状況によって免税にならない場合があります。
  • 実態のない法人は問題になり得る：事業の実態や取引の合理性がないまま、個人の収入を法人に付け替えるような使い方は、税務上の問題になるおそれがあります。何を法人で行い、何を個人で行うかは、税理士と相談して決めてください。

向いている可能性がある人・向いていない可能性がある人

向いている可能性がある人向いていない可能性がある人
  • 所得が一定以上あり、個人事業のままだと税金・国民健康保険料の負担が大きいと感じている
  • 法人名義での契約や信用が必要な事業を行っている
  • 法人で行う事業の実態（契約、業務、売上）をはっきり説明できる
  • 決算・申告の費用を払っても、メリットが残るか試算した
  • 所得がまだ小さく、法人の維持費や社会保険料の増加のほうが大きくなりそう
  • 節税だけを目的にして、事業の実態が伴わない
  • 社会保険に加入するための保険料を、毎月負担できる見通しがない
  • 決算や税務の管理を続ける時間も費用もない

検討するときの進め方

  1. 今の負担を把握する：売上と経費から、税金と社会保険料の概算を出します（手取りシミュレーター）。
  2. 法人にした場合の姿を想定する：役員報酬の額、社会保険料、法人税、法人住民税、決算・申告の費用を並べます。
  3. 消費税とインボイスを確認する：取引先がインボイスを求めるか、自分の売上が免税の範囲かを確認します。
  4. 税理士に相談する：個別の試算と実態面のアドバイスは、専門家に依頼するのが安全です。
  5. 設立の方法を選ぶ：自分で設立する、専門家に依頼する、パッケージを使う、の中から選びます。

よくある疑問

マイクロ法人にすれば、社会保険料は必ず安くなりますか？

必ずではありません。役員報酬の額や自治体の国民健康保険の料率などによって、増える場合もあります。将来の年金や給付の面も含めて、総合的に考える必要があります。

個人事業主のまま、売上の一部を法人に移してもいいですか？

事業の実態や取引の合理性が問われるため、一概には言えません。同じ業務を名義だけ分けるような使い方は、税務上の問題になるおそれがあります。税理士に相談してください。

法人は社会保険に入らなくてもよいですか？

日本年金機構は、法人の事業所（事業主のみの場合を含む）は厚生年金保険の適用事業所になると案内しています。例外の手続きもあるため、詳しくは年金事務所や社会保険労務士、税理士に確認してください。

まとめ

マイクロ法人は、社会保険、税金、消費税、取引先との契約など、複数の要素を組み合わせて考える選択肢です。得になる場合もありますが、社会保険の負担や決算・申告のコスト、役員給与のルールなどを含めて比較する必要があります。まずは現状の負担を把握し、法人化の目安を確認したうえで、税理士に試算を相談してください。
